# Rule index

Every rule in `headwall-nag-cleanup.php` as of **1.25.0**, by mechanism. Version column is
the release the rule was verified against — if the vendor on a site is newer, re-verify
before trusting the rule.

Mechanisms, lowest-numbered preferred: **1** vendor opt-out hook · **2** targeted unhook ·
**3** dashboard widget removal · **4** stored-notification removal. Full definitions and the
boundary rule are in `CLAUDE.md`.

A plugin analysed with **no** rule still has a document — absence from this index is not
absence from the audit. `ls docs/plugins/` is the full list of everything examined.

## Mechanism 4 — stored-notification removal

The last resort, and the only mechanism that **writes to another vendor's data**. Read the
Mechanism 4 constraints in `CLAUDE.md` before adding one.

| Rule method | Phase | Store | Vendor verified against | Doc |
|---|---|---|---|---|
| `remove_rank_math_stored_promos` | `all_admin_notices` @ 1 | `rank_math_notifications` option, via the vendor's own `remove_by_id()` | Rank Math SEO 1.0.278, Pro 3.0.95 | [seo-by-rank-math.md](seo-by-rank-math.md) |

IDs are named in `RANK_MATH_PROMO_NOTIFICATION_IDS`. **The two gate each other** — removing
one alone lets the other appear, so do not trim that constant to a single entry.

## Shared machinery

| Symbol | What it is |
|---|---|
| `find_instance_callback()` | The **only** sanctioned `$wp_filter` reader. Matches one class and one method by `instanceof`, inspects no content. Never add a second; extend this one |
| `remove_discarded_instance_callback()` | Front door to the above: find the entry, remove it, log it. Used by every `†` rule |
| `hide_freemius_promo_notice()` | Mechanism 1 callback for `fs_show_admin_notice_{slug}`. Passes the incoming value straight back for ids we do not claim |
| `disable_wpchill_telemetry()` | Mechanism 1 callback for `wpchill_telemetry_config` |
| `get_freemius_module()` | Reaches a Freemius module by id without booting the SDK |
| `get_elementor_admin_notices_component()` | Reaches Elementor's admin-notices component |
| `log()` | Gated on `HEADWALL_NAG_CLEANUP_DEBUG`. Logs what **happened**, never what was registered |
